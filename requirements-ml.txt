#       uv venv --python 3.12
#       uv pip install torch torchvision --index-url https://download.pytorch.org/whl/cu130
#       uv pip install -r requirements-ml.txt
#   (Verified with torch 2.13.0+cu130 on an RTX 3090.)
#
# Note: scripts import `datasets` before `torch` on purpose -- importing torch first
# triggers a DLL load-order crash with the CUDA build on Windows. Harmless on Linux,
# kept so the scripts stay portable.
